PLOTTING
To plot all figures in the manuscript, run the file "MAIN_PlotAll".

GENERATING THE FILTERS
To generate the scaling filter H and wavelet filters G1, G2, G3 of the scaling function and wavelets in the manuscript, call the function MAIN_Filters in MATLAB command prompt by typing:

[H,G1,G2,G3] = MAIN_Filters("filename") where filename can be any of Fig47, Fig48, ..., Fig414.
