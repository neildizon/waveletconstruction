# Wavelet Construction Projects

This repository groups four related project archives:

- [Quaternionic Wavelet Feasibility Problem](Quaternionic%20Wavelet%20Feasibility%20Problem/) — solver code and manuscript materials.
- [Extended Feasibility Problem on the Line](Extended%20Feasibility%20Problem%20on%20the%20Line/) — one-dimensional feasibility experiments and manuscript materials.
- [Extended Feasibility Problem on the Plane](Extended%20Feasibility%20Problem%20on%20the%20Plane/) — two-dimensional feasibility experiments and manuscript materials.
- [Optimization Approach Using Zak Transform](Optimization%20Approach%20Using%20Zak%20Transform/) — optimization and iterative reconstruction materials.

The original `README.txt` files are kept with their respective projects. The archives include MATLAB code and data, figures, spreadsheets, and a Maple worksheet.
