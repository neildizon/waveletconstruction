PLOTTING
To plot all figures in the manuscript, run the file "MAIN_PlotAll".

GENERATING THE FILTERS
To generate the scaling filter H and wavelet filter G of the scaling function and wavelets in the manuscript, call the function MAIN_Filters in MATLAB command prompt by typing:

[H,G] = MAIN_Filters("filename") where filename can be any of Fig41, Fig42, ..., Fig46.
