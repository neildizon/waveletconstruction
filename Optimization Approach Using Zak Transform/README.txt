SOLVE_AND_PLOT FOLDER
 
1. The Maple file "Constraints.mw" symbolically computes the constraint sets.
2. For examples of solving the optimisation problem, run the files pre-fixed by "SOLVE_"
3. The files pre-fixed by "MAIN_" contains minimisers obtained from solving the optimisation problems. Running these files will generate a plots of scaling functions based on the minimisers.
4. The files pre-fixed by "PLOT_" will generate the plots used in the manuscript.

ITERATIVE_RECONSTRUCTION FOLDER

1. Inside the folder named pre-fixed by "NearCardinal_", run the file "MAIN_Reconstruction" for an example of an iterative reconstruction.
2. Inside the folder named "Convergence", run the file "convergenceplots" to plot to compare the convergence of reconstructions in "NearCardinal_Daubechies" and "NearCardinal_New".
